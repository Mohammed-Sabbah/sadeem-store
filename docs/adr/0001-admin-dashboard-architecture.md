# ADR 0001: المعمارية العامة للوحة تحكم إدارة سَدِيم (Admin Dashboard Architecture)

## الحالة (Status)
معتمد (Accepted).

## السياق (Context)
يحتاج فريق إدارة منصة سَدِيم (سوبر أدمن والعمليات الميدانية في المحافظة الوسطى) إلى لوحة تحكم مركزية وشاملة تمكنهم من:
1. الرقابة على كتالوج المنتجات وتجميد الأصناف المخالفة.
2. إدارة انضمام وتجميد المتاجر ومتابعة أدائها ومبيعاتها.
3. إدارة حسابات الزبائن والبت في طلبات شحن وسحب أرصدة المحافظ.
4. فرز وتوزيع الطلبيات الميدانية وإسنادها لمناديب التوصيل.
5. إدارة المناديب، متابعة مهامهم، واحتساب مستحقاتهم.
6. إدارة الخزينة والتسويات المالية اليدوية (كاش / جوال باي) مع المتاجر والمناديب وتوثيقها.

## القرارات المعتمدة (Decisions)
1. **لغة التصميم (UI Philosophy):** تبني نفس فلسفة "الفخامة الكونية الهادئة" (Cosmic Quiet Luxury) وشبكة الألوان والأنماط المعيارية المستخدمة في لوحة التاجر (`tokens.css`، خط المراعي، كروت 14px، أزرار 8px ناعمة، صفر تكدس صناديق).
2. **هيكل التنقل (Navigation Layout):** اعتماد شريط جانبي هادئ وقابل للطي (Collapsible Sidebar) بأسلوب Apple و Linear، يضم الأقسام السبعة، مع تحول تلقائي لدرج انزلاقي أنيق على الجوال:
   - 📊 النبض والإحصائيات العامة (`/admin/dashboard` أو `/admin/analytics`)
   - 🛍️ الطلبات والتوزيع الميداني (`/admin/orders`)
   - 🏪 شبكة المتاجر (`/admin/stores`)
   - 📦 رقابة الكتالوج والأصناف (`/admin/products`)
   - 🛵 المناديب والعمليات (`/admin/couriers`)
   - 👥 الزبائن والمحافظ (`/admin/customers`)
   - 💰 الخزينة والتسويات المالية (`/admin/finances`)
3. **السياسة الأمنية والصلاحيات:** مسار محمي ومغلق `/admin/*` يتطلب مصادقة JWT مع التحقق الصارم من دور المستخدم (`role === 'admin'`).

## النتائج والآثار (Consequences)
- سيتم تحديث هذا السجل بصيغته النهائية فور إتمام جولات الاستجواب المعماري (`/grill-with-docs`) واعتماد كافة القرارات مع صاحب المشروع.
