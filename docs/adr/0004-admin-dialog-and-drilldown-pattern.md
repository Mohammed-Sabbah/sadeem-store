# ADR 0004: نمط التفاعل والنوافذ في لوحة الإدارة (Admin Dialog & Drilldown Pattern)

## الحالة (Status)
معتمد (Accepted).

## السياق (Context)
أثناء دراسة تجربة المستخدم (UX) للوحة إدارة سَدِيم لتوفير أقصى قدر من السرعة والإنتاجية للإدارة، برزت الحاجة للاختيار بين:
1. الاعتماد على صفحات منفصلة لكل عملية (Full Pages).
2. الاعتماد على نوافذ منبثقة أو أدراج جانبية (Modals / Slide-over Drawers).

## القرار المعتمد (Decision)
اعتماد **النمط الهجين الذكي (Context-Preserving Hybrid Pattern)**:

1. **العمليات الإجرائية السريعة (In-Context Actions):**
   - تُنفذ عبر **نوافذ منبثقة هادئة (Modals)** أو **أدراج منزلقة ناعمة (Slide-over Drawers)** دون مغادرة الصفحة أو فقدان حالة الفلاتر والتمرير:
     - إضافة / تعديل فئة (Category Form).
     - نافذة تجميد متجر أو إيقاف صنف مع كتابة سبب الإيقاف.
     - مراجعة سريعة واعتماد طلب انضمام متجر (Store Approval Quick Review).

2. **الاستعراض العميق الشامل (Deep Drilldown Pages):**
   - يُخصص لها مسار كامل عند الحاجة لاستعراض سجلات ضخمة تتطلب مساحة كاملة:
     - صفحة تفاصيل المتجر الشاملة (`/admin/stores/[id]`) التي تضم كتالوج منتجاته، إحصائياته الكاملة، وسجل حركاته.

## النتائج والآثار (Consequences)
- الحفاظ التام على تركيز الآدمن أثناء العمل اليومي السريع، مع انعدام "إرهاق التنقل وإعادة التحميل".
- تجربة استخدام فائقة السلاسة على الجوال وسطح المكتب على حد سواء.
