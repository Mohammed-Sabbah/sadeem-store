مرجع التنفيذ هو `account-cart.md` وADR 0015. معيار النجاح هو اجتياز حالات القبول، وعزل الحسابات، ونقل المصدر مرة واحدة، واستهلاك المشتريات داخل المعاملة دون فقد إضافات جديدة.

## نقطة تنظيم العمل

- **Blocking first steps.** تثبيت العقد وفحص MongoDB قبل الربط. قاعدة محلية تدعم `rs0` متاحة، وتستخدم الاختبارات قاعدة منفصلة فقط.
- **Independent workstreams.** وحدة الباك إند وواجهة السلة ملفات منفصلة مع عقد API واحد. المنسق يراجع التكامل والتوثيق، ومراجع مستقل يتحدى التصميم.
- **Shared mutable state.** ملكية ملفات الباك لمُنفّذ الباك، وملفات الواجهة لمُنفّذ الواجهة. كل تغيير للسلة على السيرفر مشروط بمراجعة ويملك هوية حساب.
- **Smallest safe decomposition.** منفذ لكل جانب ومراجع قراءة فقط. لا يُشغّل منفذان على الملف نفسه. الملفات الحالية المعدلة من المستخدم محفوظة، ويُستثنى فرق المستخدم من commit المهمة.

الاختبارات الجديدة كشفت الخلل قبل إصلاحه في الحذف المؤجل وتحويل null/القيمة الفارغة إلى سعر صفر. أضيفت اختبارات إعادة الإضافة دون انتظار render، والرد المفقود، وتلف JSON، وتصحيح مصدر نقل مرفوض. فحوص المتصفح تستعمل API تجريبية؛ فحوص الباك تتصل بـMongoDB فعلية وقاعدة اختبار معزولة.

## الحدود المعروفة

- نقل المصادر المحلية يستخدم Web Locks على متصفح حديث وسياق آمن. عند غيابها أو تعذر قراءة مصدر محلي، تبقى سلة السيرفر قابلة للاستخدام مع تنبيه، والمصدر محفوظ.
- خيار قديم حُذف كليًا من الكتالوج قبل نقله يرفض النقل ذريًا، ويظهر ضمن المصدر المعلق للمراجعة والحذف الصريح. لا يُخمن بديل عنه.
- الاختبارات لا تصلح أخطاء lint القديمة غير المرتبطة بالمهمة، ولم نُعد تصميم الدفع أو التسعير.

## قرارات إضافية أثناء المراجعة

- الطلب يحمل الحساب المقصود ويقارنه السيرفر بصاحب الجلسة. هذا يمنع طلبًا معدًا لحساب قديم من تعديل الحساب الذي دخل لاحقًا.
- إيصالات النقل في مجموعة منفصلة ذات معرّف فريد؛ تبقى بعد إفراغ السلة والشراء لتفادي تكرار النقل.
- الفشل الملتبس في حفظ تعديل لا يسمح بإعادة إضافة عمياء بمعرّف جديد. تُسترجع السلة المؤكدة قبل تعديل جديد.
- لا يوجد اعتماد تشغيل جديد. محاولة تجهيز Playwright مؤقتًا لم تكتمل، فاستخدمنا Chromium المثبت مسبقًا عبر CDP وواجهة WebSocket المدمجة في Node.

## ملاحظات المهارات

ملفا `implement` و`poteto-mode` مقروءان. أداة `Skill` غير متاحة في هذا العميل، وعدد من المهارات الفرعية المشار إليها مثل `tdd` وملفات `principle-*` غير مثبت محليًا. نطبق دورة اختبار سلوكي يفشل ثم ينجح، ومراجعة الفرق قبل commit بأدوات العميل المتاحة. لا ندعي استدعاء أدوات أو قراءة ملفات غير متاحة. أسماء موديلات Cursor الافتراضية غير متاحة هنا؛ يستعمل الوكلاء موديل الجلسة المدعوم.
